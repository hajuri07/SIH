# Screenshots

Screenshots need the running system, so they are yours to capture. Save PNGs in this folder using these names.

| File name | What to capture | When |
| :--- | :--- | :--- |
| `01_swagger_overview.png` | `http://127.0.0.1:8000/docs` showing all endpoint groups | API running |
| `02_seed_output.png` | Terminal after `python -m arena6.seed_db` | after seeding |
| `03_demo_views.png` | Terminal after `python -m arena6.show_demo_data` | after seeding |
| `04_pytest_summary.png` | Final pytest summary line with passed/xfailed counts | after tests |
| `05_predict_unit73.png` | Swagger: `POST /api/v1/predict/rul` for unit 73 and its response | demo engine |
| `06_explain_unit73.png` | Swagger: `GET /api/v1/explain/73` response | demo engine |
| `07_dashboard_unit73.png` | Dashboard, unit 73, "Degradation & Telemetry" tab | dashboard running |
| `08_dashboard_anomaly.png` | Dashboard, "Anomaly Radar & Lead Time" tab | dashboard running |
| `09_dashboard_shap.png` | Dashboard, "AI Explainability (SHAP)" tab | dashboard running |
| `10_dashboard_leaderboard.png` | Dashboard, "Model Leaderboard" tab | dashboard running |
| `BUG-0XX_<name>.png` | One per confirmed bug (see `docs/BUG_REPORTS.md`) | when a bug is confirmed |

Tips: use the same browser zoom for all shots, hide bookmarks, and include the URL bar so the page is identifiable.
