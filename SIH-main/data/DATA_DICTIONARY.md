# C-MAPSS Turbofan Engine Dataset: Data Dictionary

## 1. Overview
The Commercial Modular Aero-Propulsion System Simulation (**C-MAPSS**) dataset is a benchmark dataset generated by NASA for prognostics, health management (PHM), and Remaining Useful Life (**RUL**) prediction of commercial turbofan jet engines.

A high-bypass turbofan engine is simulated across multiple operational flights under different atmospheric regimes until run-to-failure degradation is observed.

## 4. Modeling Assumptions & Degradation Target Formulation

### 4.1 Piecewise Linear Degradation Target
In real-world turbomachinery, brand-new or newly serviced engines do not experience linear wear immediately. They operate in a healthy baseline equilibrium for an extended period until microscopic defects (e.g., blade fouling, thermal erosion, or seal clearance expansion) begin to propagate.

Therefore, we implement the industry-standard **Piecewise Linear RUL Target Function**:
$$\text{RUL}_{\text{target}}(t) = \min(R_{\text{max}}, T_{\text{fail}} - t)$$
- We set $R_{\text{max}} = 125$ cycles.
- For cycles where true remaining life is greater than 125, the target is clipped at 125 to avoid predicting unbounded health states.

### 4.2 Invariant Sensor Filtering
In dataset FD001 (Sea Level, single operating condition), 7 sensors (`s_1`, `s_5`, `s_6`, `s_10`, `s_16`, `s_18`, `s_19`) and setting 3 (`setting_3`) exhibit zero variance across all cycles. Retaining constant columns adds noise to gradient computations and distance metrics; our data cleaning pipeline systematically detects and eliminates zero-variance channels.

### 4.3 Feature Normalization Strategy
Min-Max normalization is fitted exclusively on the training engine cohort:
$$x_{\text{norm}} = \frac{x - x_{\text{min, train}}}{x_{\text{max, train}} - x_{\text{min, train}}}$$
Parameters are frozen and applied to test engines and real-time streaming telemetry to prevent data leakage.
